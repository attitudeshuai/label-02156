# 设计规范 - 图书管理系统前端

> 版本: 1.0  
> 创建时间: 2026-02-08

---

## 1. 色彩体系

### 主色调
| 名称 | 色值 | 用途 |
|------|------|------|
| Primary | `#409EFF` | 主操作按钮、导航高亮、链接 |
| Primary Light | `#79BBFF` | 次要操作、悬停状态 |
| Primary Dark | `#337ECC` | 按钮按下状态 |

### 功能色
| 名称 | 色值 | 用途 |
|------|------|------|
| Success | `#67C23A` | 成功状态、已归还 |
| Warning | `#E6A23C` | 警告状态、即将逾期 |
| Danger | `#F56C6C` | 错误状态、已逾期、删除 |
| Info | `#909399` | 辅助信息、禁用状态 |

### 中性色
| 名称 | 色值 | 用途 |
|------|------|------|
| Text Primary | `#303133` | 主要文字 |
| Text Regular | `#606266` | 常规文字 |
| Text Secondary | `#909399` | 次要文字 |
| Text Placeholder | `#C0C4CC` | 占位符 |
| Border | `#DCDFE6` | 边框 |
| Background | `#F5F7FA` | 页面背景 |
| White | `#FFFFFF` | 卡片背景 |

## 4. 组件规范

### 按钮
- 主按钮: 蓝色填充，白色文字
- 次按钮: 白色填充，蓝色边框
- 危险按钮: 红色填充，用于删除操作
- 圆角: 4px

### 表格
- 斑马纹显示
- 行高: 48px
- 表头背景: #FAFAFA
- 悬停背景: #F5F7FA

### 表单
- 标签宽度: 100px
- 输入框高度: 40px
- 必填项红色星号标识

### 弹窗
- 宽度: 500px (表单弹窗)
- 圆角: 8px
- 标题字号: 18px

### 卡片
- 圆角: 8px
- 阴影: 0 2px 12px rgba(0, 0, 0, 0.1)

### 主布局

|    Sidebar       |       Content          |

### 侧边栏
- 宽度: 220px (展开) / 64px (收起)
- 背景: #304156
- 菜单项高度: 50px
- 激活状态: 左侧 3px 蓝色边框 + 背景高亮

### 头部导航
- 高度: 56px
- 背景: #FFFFFF
- 阴影: 0 1px 4px rgba(0, 0, 0, 0.08)

## 6. 交互规范

### 反馈状态
- Loading: Element Plus 的 v-loading 指令
- 成功提示: ElMessage.success()
- 错误提示: ElMessage.error()
- 确认弹窗: ElMessageBox.confirm()

### 空状态
- 使用 Element Plus Empty 组件
- 配合操作引导按钮

### 表格操作
- 操作按钮使用文字按钮
- 删除操作需二次确认
- 批量操作需选中提示
